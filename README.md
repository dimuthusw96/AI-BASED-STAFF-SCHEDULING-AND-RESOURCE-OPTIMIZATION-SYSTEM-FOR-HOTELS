## 📖 About the Project

Traditional, manual staff scheduling in hotels is time-consuming and highly prone to human error, often resulting in overstaffing (wasted resources) or understaffing (poor customer experience). 

This project solves this by introducing a centralized, AI-driven dashboard. It forecasts future staffing requirements based on historical hotel demand and automatically creates rosters that align with budget constraints and employee roles.

---

## ✨ Key Features

* **🤖 AI-Powered Roster Generation:** Automated scheduling based on predicted demand using machine learning models.
* **👥 Comprehensive Staff Management:** Add, update, and manage employee profiles, roles (e.g., Front Desk, Housekeeping), and hourly rates.
* **📊 Resource & Cost Optimization:** Real-time calculation and tracking of staffing costs to prevent budget overruns.
* **⚡ Interactive Dashboard:** A dynamic, seamless user interface built with Blazor for instantaneous data updates without page reloads.
